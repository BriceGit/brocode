# Brocode — test Obsidian-native

Ces fichiers gardent **les mêmes noms que les originaux** afin de pouvoir les remplacer directement après sauvegarde externe.

Couche ajoutée :
- Properties YAML homogènes ;
- un seul H1 par note ;
- hiérarchie de headings adaptée à l’Outline ;
- navigation précédent / suivant en wikilinks ;
- callout natif pour l’objectif quand il existe ;
- aucun plugin requis.

Le fond des chapitres est conservé. Le titre interne du chapitre UDF / Window Functions a été harmonisé de `05` vers `09` pour correspondre au fichier `09_...` et à l’ordre transmis.
